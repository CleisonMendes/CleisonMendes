# Aurora — GitHub Profile README

## Como publicar

1. Baixe e extraia `aurora-github-profile.zip`.
2. No GitHub, abra o repositório de perfil `CleisonMendes` (o nome precisa ser exatamente igual ao seu usuário).
3. Faça upload do `README.md` e da pasta `assets` mantendo a estrutura.
4. Se o repositório ainda não existir, crie um repositório **público** chamado `CleisonMendes` e marque **Add a README file**.
5. Confira o perfil em https://github.com/CleisonMendes.

## Atenção antes de publicar

- Os SVGs desta pasta são artes vetoriais criadas para a identidade Aurora.
- Os cards de estatísticas, o typing SVG e o streak são serviços externos; podem ficar temporariamente indisponíveis.
- O card de linguagens representa estatísticas dos repositórios públicos, não uma avaliação de proficiência.
- Revise as descrições dos projetos e tecnologias para refletirem exatamente o que está publicado.
- O link do LinkedIn está configurado como `https://www.linkedin.com/in/cleison-mendes`. Confirme se esse é o endereço público correto.
- O FraudShield aparece como projeto em destaque, mas não foi colocado um link porque o endereço do repositório não foi confirmado.
